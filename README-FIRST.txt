How to get the .exe (about 5 minutes, no coding):
1. Create a free account at github.com and make a NEW repository (private is fine).
2. Click "uploading an existing file", drag in EVERYTHING from this folder
   (including the hidden .github folder), and commit.
3. Open the "Actions" tab -> wait ~3-5 min for "Build Windows installer" to turn green.
4. Open that run -> download the "BAC-QUEST-Setup" artifact -> unzip -> run the .exe.
It installs in one click and puts a BAC QUEST shortcut on the desktop.
